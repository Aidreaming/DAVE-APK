# Public UK food update feed

Text-only UK subset of Open Food Facts, prepared weekly and published as immutable release assets. No app source, user profile, journal or personal data is included.

Database: Open Food Facts contributors, https://world.openfoodfacts.org — ODbL 1.0. Individual contents: DbCL 1.0. Extraction code and attribution are public. Photographs are not downloaded or distributed; optional image URLs remain links to their original source.

The catalogue is published only after all release files have uploaded successfully. Phones validate sizes, SHA-256 hashes and data structure before activating an update. GitHub service limits and availability still apply; this is not a guaranteed permanent hosting service.
